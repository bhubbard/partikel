Installation & Usage

# Install from Cargo
cargo install --path .

# Run deterministic Tier 0 tool directly
ptk run flow_matching_sigmas '{"steps": 20, "shift": 3.0}'

# Convert CSS spring timing to damping ratio & natural frequency
ptk run spring_physics_convert '{"mass": 1.0, "stiffness": 100.0, "damping": 10.0}'

# Start standard MCP stdio server
ptk mcp
